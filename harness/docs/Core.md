## How it connects
- **Uses:** `Packages.Charm` (ClientData atoms), `Packages.Signal` (ServerSignals), `Packages.Loader` (loaders, `SpawnAll` only), `CustomPackages.Plums` (PlumsType).
- **Used by:**
  - `SoundsService.PlaySound`: MonetizationController. `PlaybackSpeed` / `PitchVariation`: no caller in `src/` yet.
  - `NumberUtil.FormatWithSuffix`: Leaderboards (`Leaderboard.luau`).
  - `LoopService`: GuideBeamUtil. `CharacterUtil`, `ParticleUtil`, `TimeUtil`, `TweenUtil`: no callers in `src/` yet.
  - `FeelUtil`: CameraShakeUtil, FloatingTextUtil, RewardFlyUtil. `ChainStep`, `PitchForStep`: no caller in `src/` yet.
  - Feel kit: nothing in `src/` calls `CameraShakeUtil`, `HitPauseUtil`, `FloatingTextUtil`, `GuideBeamUtil` or `RewardFlyUtil.Fly` yet. `CurrencyChip`'s `FlyTarget` is not passed by any screen yet.
  - `ServerData`: PlayerSystem (writes), plus Monetization, Onboarding, Cutscenes, Leaderboards and Inputs (read / Plum writes).
  - `ClientData`: PlayerController (sync), Gui (Menu, `Gui.Toasts`), Inputs.
  - `SharedConfigs`: PlayerDataTemplate, Inputs, Onboarding, Feel (feel kit, ToastService).
- **Starts:** the Loaders require every `*System` / `*Controller` and call its `Init`.

## Public API

### LoopService
Runs on `RenderStepped` on the client and `Heartbeat` on the server. The connection is made when the module is first required.

#### `LoopService.AddLoop(callback: (dt: number) -> (), config: LoopConfig?) -> () -> ()`
- Adds `callback` to the frame loop. Returns a function that removes this loop. Calling it more than once is safe.
- `config.Index: string?`: a name used by `RemoveLoop`.
- `config.RunPerSecond: number?`: optional. `nil` means the callback runs every frame with `dt`. When set, despite the name, it is an **interval in seconds**: the callback runs once each time that many seconds have passed, and receives `0`, not dt (see Gotchas).
- `config.RemoveOnElapsedTime: number?`: the loop removes itself once this many seconds have passed. It still runs on that last frame. This is ignored if `RunPerSecond` is set.
- With no config, the callback runs every frame with `dt`.

```lua
local stop = LoopService.AddLoop(function(dt) spin(dt) end, { Index = "Spin" })
LoopService.AddLoop(saveTick, { RunPerSecond = 5 }) -- every 5 s
```

#### `LoopService.RemoveLoop(index: string) -> boolean`
- Removes the first loop whose `Config.Index == index`.
- Returns `true` if one was removed, `false` if none matched.

### SoundsService
The module's local table is named `SoundSystem`. Sounds are looked up in `SoundService` by name. The settings and playlist state belong to the environment that requires it, so on the client they apply to that one player.

#### `SoundsService.PlaySound(sound: Sound | string | {string}, config: PlayConfig?) -> Sound?`
- Plays a Sound, a sound found by name (`FindSoundByName`), or one name picked at random from a list.
- **Yields** until the sound has loaded (`Loaded:Wait()`).
- Returns `nil` (and plays nothing) if sound effects are off (`EnablePlaySound(false)`), the list is empty, or the name isn't found (it warns, unless `IgnoreMissing`).
- Returns the instance that played: the clone when one was made, otherwise the original.
- `PlayConfig` fields (all optional):
  - `Clone`: plays a copy, which starts at TimePosition 0. Setting `Position`, `PlaybackSpeed` or `PitchVariation` also makes a copy.
  - `Position: Vector3`: plays the copy from an invisible anchored part at that point, parented to `Parent` or `workspace`.
  - `Parent`: where the sound goes. A clone with no Parent or Position goes to `SoundService.Extra`, which is created if missing.
  - `Volume`: set if given.
  - `PlaybackSpeed: number`: pitch and speed (1 normal, 2 an octave up). Implies a copy, so the original keeps its pitch. `FeelUtil.PitchForStep` gives a value for a climbing chain.
  - `PitchVariation: number`: a random ± fraction on top of the speed (0.08 = up to 8% either way). Implies a copy.
  - `Looped`, `PlayOnRemove` (when true, `Play()` is not called): a copy defaults both to `false`. The original sound is only changed when the config gives the field, so otherwise it keeps its own settings.
  - `DebrisDuration`: a clone is destroyed after this many seconds. A non-clone gets `StopSound` after this many seconds.
  - Without `DebrisDuration`, a non-looped clone is destroyed after `TimeLength / PlaybackSpeed + 0.2` (a slower copy plays longer, so it lives longer). A looped clone lives until it's destroyed.
  - `FadeIn`: fades up from 0 to the volume over this many seconds.
  - `FadeOut`: when the sound is destroyed while playing, a copy fades it out over this many seconds instead of cutting it off.
  - `IgnoreMissing`: a sound name that isn't found plays nothing **without** a warning (for placeholder sounds not added yet).

```lua
SoundsService.PlaySound("Purchase", { Clone = true })
SoundsService.PlaySound({ "Pop1", "Pop2" }, { Position = part.Position, Volume = 0.5 })
SoundsService.PlaySound("Pickup", { PlaybackSpeed = FeelUtil.PitchForStep(step, SharedConfigs.Feel.PitchMaxSteps) })
```

#### `SoundsService.StopSound(sound: Sound | string) -> ()`
- Calls `:Stop()` on the Sound, or on the sound found by name. Does nothing if the name isn't found (it warns).

#### `SoundsService.FindSoundByName(name: string, quiet: boolean?) -> Sound?`
- Returns the first Sound named `name` that is a direct child of `SoundService` or anywhere inside one of its children. `SoundService.Extra` is skipped.
- Returns `nil` if none is found, and warns `"No sound found named <name>"` unless `quiet` is true.

#### `SoundsService.EnablePlaySound(enable: boolean) -> ()`
- The SFX setting. `false` stops `PlaySound` and moves every non-music Sound under `SoundService` and `workspace` into a `MutedEffects` SoundGroup with volume 0. Sounds added later are moved too.
- `true` puts each sound back in its previous SoundGroup and stops watching for new sounds.

#### `SoundsService.SetMusicEnabled(enabled: boolean) -> ()`
- The music setting. Works on every Sound under `SoundService.Music`, which may be missing. Does nothing if the value hasn't changed.
- `false` remembers each track's volume and holds it at 0. Any later volume change is remembered as the new level, then forced back to 0.
- `true` restores the remembered volumes.

#### `SoundsService.PlayListsPlay(playListName: string?, random: boolean?, index: number?) -> ()`
- Starts playlist `playListName` (default `"Main"`) from `PlayLists`. It loops forever, moving to the next track when one ends and wrapping to the first.
- `random`: start on a random track. `index`: start on this track (1-based, default 1).
- If a playlist is already running, its track is stopped first (through `NextOnCurrentPlayList`), so tracks don't overlap.
- Does nothing if the playlist doesn't exist.

#### `SoundsService.NextOnCurrentPlayList() -> ()`
- Stops the track that's playing, then plays the next one (wrapping to 1) and hooks its `Ended` to keep the playlist going. Does nothing if no playlist is running.

#### `SoundsService.StopCurrentPlayList() -> ()`
- Stops the current track and clears all playlist state.

#### `SoundsService.MuteCurrentPlayList() -> ()` / `SoundsService.UnmuteCurrentPlayList() -> ()`
- Sets every track in the current playlist to volume 0, or back to its `DefaultVolume`. Does nothing if no playlist is running.

#### `SoundsService.PauseCurrentPlayList() -> ()` / `SoundsService.UnpauseCurrentPlayList() -> ()`
- `Pause()` the current track, or `Resume()` it if it isn't playing. Does nothing if no playlist is running.

#### `SoundsService.DistortCurrentPlaylist(enabled: boolean, callback: (() -> ())?) -> ()`
- `true`: tweens every track's `PlaybackSpeed` to 0.2 over 5 s, then calls `callback` after 5 s (`task.delay`).
- `false`: sets `PlaybackSpeed = 1` right away. The callback is not used.
- Does nothing if no playlist is running.

#### PlayLists
- Shape: `{ [name]: { { Name: string, Sound: Sound, DefaultVolume: number } } }`. Empty by default. Tracks normally live in `SoundService.Music`.

### SharedUtilities
`require(ReplicatedStorage.SharedUtilities)` returns `{ CharacterUtil, DeveloperUtil, FeelUtil, InputUtil, MaterialUtil, MonetizationUtil, NumberUtil, ParticleUtil, ThemeUtil, TimeUtil, TuningUtil, TweenUtil }`. Always require this main module, then read the sub util from it.

```lua
local SharedUtilities = require(ReplicatedStorage.SharedUtilities)
local FormatWithSuffix = SharedUtilities.NumberUtil.FormatWithSuffix
```

### CharacterUtil

#### `CharacterUtil.GetHumRootFromPlayer(player: Player) -> BasePart?`
- Returns the character's `HumanoidRootPart` (only if it is a BasePart).
- Returns `nil`, without erroring, when the player has no character or no root part.

#### `CharacterUtil.GetHumanoidFromPlayer(player: Player) -> Humanoid?`
- Returns the character's first `Humanoid` child (`FindFirstChildOfClass`, so the name doesn't matter).
- Returns `nil`, without erroring, when the player has no character or no Humanoid.

```lua
local humanoid = SharedUtilities.CharacterUtil.GetHumanoidFromPlayer(player)
if humanoid then humanoid.Health = 0 end
```

#### `CharacterUtil.ApplyHumanoidDescription(userId: number, model: Model) -> boolean`
- Dresses the first Humanoid found anywhere in `model` as `userId`'s avatar. **Yields** (web call).
- Returns `false` (with a warning) if there's no humanoid, the fetch fails, the humanoid was removed during the fetch, or `ApplyDescription` fails. Returns `true` on success.

#### `CharacterUtil.CharacterVisibility(player: Player, visible: boolean, excluded: ({string | BasePart} | string | BasePart)?) -> ()`
- Sets `Transparency` to 0 (visible) or 1 on every BasePart (except `HumanoidRootPart`) and every Decal in the character. Does nothing if the character is missing.
- `excluded`: parts left alone, given as the BasePart itself or a **CollisionGroup name** (not a part name). Decals are never excluded.

### NumberUtil

#### `NumberUtil.PlayerExpRequiredCalculation(level: number) -> number`
- Returns `math.floor(100 * level ^ 1.5)`.

#### `NumberUtil.FormatWithSuffix(value: number) -> string`
- Below 1000 (including negative numbers), returns `tostring(value)` unchanged.
- Otherwise scales by K/M/B/T/Qa/Qi/Sx/Sp/Oc/No, truncates to 2 decimals and drops trailing zeros (`1234 -> "1.23K"`, `1000 -> "1K"`).

#### `NumberUtil.FormatDecimal(value: number) -> string`
- Same suffixes. Below 1000 it **rounds** to 2 decimals and drops trailing zeros (`12.345 -> "12.35"`, `5 -> "5"`). At 1000 and above it truncates like `FormatWithSuffix`.

#### `NumberUtil.FormatWithCommas(value: number) -> string`
- Adds thousands separators to `tostring(value)` (`1234567 -> "1,234,567"`). A decimal part is kept as is.

#### `NumberUtil.GetNumberFromString(str: string, inNumber: boolean) -> (string | number)?`
- Returns the first run of digits (`"Test12" -> "12"`). Signs and decimals are ignored.
- Returns a number if `inNumber` is true, otherwise a string. Returns `nil` if there are no digits.

#### `NumberUtil.GetUniqueNumberID(list: {}) -> number`
- Returns the lowest positive integer not used as a key in `list`. Number keys count, and so do the digits in string keys (`"Dna3"` counts as 3).

### ParticleUtil

#### `ParticleUtil.EmitParticles(source: BasePart | ParticleEmitter, emitOptions: EmitOptions?) -> ()`
- Bursts every ParticleEmitter inside a part (any depth), or a single emitter, with `Emit(count)`. Does nothing if `source` is nil.
- Never touches `Enabled`: each emitter keeps its own state, so a disabled emitter stays disabled after the burst.
- Count per emitter: the `EmitCount` option, else the emitter's `EmitCount` attribute, else `DefaultEmitCount` (20). The burst is delayed by the emitter's `EmitDelay` attribute (default 0).
- **Copy or in place:** `Clone`, `EmitAt`, `Parent`, or `Size` (part sources only) make it emit from a copy, so the original is never moved, reparented or resized. With none of them it emits from the original in place.
- `EmitOptions` (all optional):
  - `EmitCount: number`: particles per emitter.
  - `Clone: boolean`: emit from a copy.
  - `EmitAt: Vector3`:
    - Emitter: the copy emits from a new Attachment in `workspace.Terrain` at that point.
    - Part: the copy is pivoted to that point.
  - `Parent`: where the copy goes (an emitter copy with `EmitAt` goes in its Attachment instead). Default: the source's parent.
  - `Size: Vector3`: the part copy's size. Ignored for an emitter source.
  - `DestroyAfter: boolean`: destroy the target once its longest `Lifetime.Max + EmitDelay` has passed. Copies (and the `EmitAt` Attachment) are always destroyed this way; with `DestroyAfter` the **original** is destroyed too when no copy is used.
- A copy emits one frame later (`task.defer`). In place, it emits right away.

```lua
SharedUtilities.ParticleUtil.EmitParticles(effectPart, { EmitAt = hitPosition, EmitCount = 10 })
```

### TimeUtil

#### `TimeUtil.OneDelay(index: string, duration: number, callback: () -> ()) -> ()`
- A debounced `task.delay`: cancels any pending delay with the same `index`, then schedules `callback` after `duration`.

#### `TimeUtil.InCooldown(cooldownTime: number, timeStamp: number, timeType: ("Clock" | "Tick")?) -> boolean`
- `"Clock"` (default): `os.clock() - timeStamp < cooldownTime`.
- `"Tick"`: uses `os.time()` (whole seconds), **not** `tick()`.

#### `TimeUtil.GetUniversalTime(date: {year, month, day, hour?, minute?, second?}) -> DateTime`
- Returns `DateTime.fromUniversalTime(...)`. Missing hour, minute and second default to 0.

#### `TimeUtil.GetLocalTime(date: {year, month, day, hour?, minute?, second?}) -> DateTime`
- Same, using `DateTime.fromLocalTime`.

#### `TimeUtil.FormatTimeMS(seconds: number) -> string`
- `"MM:SS"` (`125 -> "02:05"`). The value is floored and clamped to at least 0.

#### `TimeUtil.FormatTimeMinSec(seconds: number) -> string`
- `"45s"` under a minute, otherwise `"2m 05s"` (seconds padded).

#### `TimeUtil.FormatDuration(seconds: number) -> string`
- `"45s"` under a minute, otherwise `"5m 5s"` (not padded). The value is floored and clamped to at least 0.

#### `TimeUtil.FormatDurationWords(seconds: number) -> string`
- `"1 Hour"` / `"2 Hours"` when `seconds` is a whole number of hours, otherwise `"<floor(seconds/60)> Minutes"`. `0` gives `"0 Hours"`.

#### `TimeUtil.FormatTimeDHMS(seconds: number) -> string`
- `"DD:HH:MM:SS"`. The value is floored and clamped to at least 0.

### TweenUtil

#### `TweenUtil.StepTweening(tweens: {Tween}, callback: (() -> ())?) -> ()`
- Plays the tweens one after another, each waiting for the last one's `Completed`, then calls `callback`. Runs in `task.spawn`, so it does **not** yield the caller.

### MaterialUtil

#### `MaterialUtil.Apply(part: BasePart, surface: string) -> boolean`
- Gives a part built in code the Studs variant for `surface`, a key of `SharedConfigs.World.MaterialVariants` (`Ground`, `Floor`, `Soil`, `Wood`, `Foliage`, `Cap`, `Rock`, `Gloss`). Sets `Material = SmoothPlastic` first (the variants are SmoothPlastic-based).
- Returns false and changes nothing for an unknown surface, a Glass / Neon / ForceField part, an invisible part (`Transparency >= 1`), or while `World.UseMaterialVariants` is false.
- Don't pass text boards or parts whose color carries meaning (items, rarity, mutations). A variant missing from `MaterialService` renders smooth, so a place without the Studs folder still works.

#### `MaterialUtil.CanApply(part: BasePart) -> boolean`
- Whether `Apply` would give this part a variant (ignores the surface).

### FeelUtil
Pure math for the feel kit: no Instances, so it's tested in Lune (`lune/Core/Shared/SharedUtilities/FeelUtil.spec.luau`). The client utils use it, and the knobs are in `SharedConfigs.Feel`.

#### `FeelUtil.AddTrauma(trauma: number, amount: number) -> number`
- `trauma + amount`, kept between 0 and 1.

#### `FeelUtil.DecayTrauma(trauma: number, dt: number, rate: number) -> number`
- `trauma - rate * dt`, never below 0.

#### `FeelUtil.ShakeAmount(trauma: number) -> number`
- The trauma squared, clamped to 0 to 1. Light shakes stay light.

#### `FeelUtil.ChainStep(lastTime: number?, now: number, resetAfter: number, step: number) -> number`
- `step + 1` when `lastTime` is set and `now - lastTime <= resetAfter`, otherwise 0 (a new chain). `lastTime` nil gives 0.
- The caller keeps `step` and `lastTime` (the time of the last pickup) and passes the previous `step` back in.

#### `FeelUtil.PitchForStep(step: number, maxSteps: number) -> number`
- A `PlaybackSpeed`: `2 ^ (step / 12)`, one semitone per step. `step` is clamped to `0` to `maxSteps`, so it stops rising at `maxSteps` (12 = one octave).

#### `FeelUtil.ShouldMerge(lastTime: number?, now: number, window: number) -> boolean`
- True when `lastTime` is set and `now - lastTime <= window`.

#### `FeelUtil.FlyIconCount(amount: number, maxIcons: number) -> number`
- `math.ceil(amount)` clamped to `1` to `maxIcons`. 0 when `amount <= 0` or `maxIcons <= 0`.

```lua
step = FeelUtil.ChainStep(lastPickup, now, SharedConfigs.Feel.PitchChainReset, step)
lastPickup = now
```

### ThemeUtil

#### `ThemeUtil.Get(styleName: string?) -> Theme`
- The theme for `styleName`, or `SharedConfigs.Themes.Active` when nil (or the Plain `DefaultTheme` when no style is active). A style is layered over `StyledBase` over `DefaultTheme`, so `theme.Plain` is false for styles and true for the default.
- A style only sets the fields its references define: everything else comes from `DefaultTheme`. The token groups (`Colors`, `Sounds`, `Spring`, `TextSizes`, `Radius`, `Spacing`, `Depth`, `Motion`, `RarityColors`, `Slices`) merge key by key (a style can change one color or one size and keep the rest).
- An unknown style warns once and gives `DefaultTheme`.
- Colors: `Background`, `Surface`, `Primary`, `Secondary`, `Accent`, `Text`, `TextMuted`, `Positive`, `Negative`, `Stroke`, plus the window and state tokens `Panel` (window body), `Body` (content area), `Header`, `HeaderBand`, `HeaderStroke`, `Premium` (Robux / VIP), `Dark` (bottom edges, shadows, overlays) and `Disabled` (disabled, locked, owned). Use these instead of adding colors mid-build.
- Tokens: `Font` / `BoldFont` / `DisplayFont` (titles, prices, big numbers), `TextSizes` (Display / Title / Body / Caption, px at phone size, Display ≈ 3× Body), `Radius` (Small / Medium / Large / Pill), `Spacing` (XS–XL px), `Depth` (`Lip`, `LipDarken`, `Lighten`, `ShadowTransparency`), `Motion` (`Open` / `Press` springs, list `Stagger` seconds), `RarityOrder` + `RarityColors`, `Slices` (optional 9-slice `Panel` / `Button` / `Card` art: `Image`, `SliceCenter`, `SliceScale?`, `Tint?`; components fall back to corners, strokes and lips when unset).
- Built once per style and cached (configs don't change at runtime): the returned table is shared, so never change it.

```lua
local theme = SharedUtilities.ThemeUtil.Get("Cartoon")
create "Frame" { BackgroundColor3 = theme.Colors.Surface, create "UICorner" { CornerRadius = theme.CornerRadius } }
```

#### `ThemeUtil.ReducedMotion() -> boolean`
- True when the player turned on Reduce Motion (`GuiService.ReducedMotionEnabled`; false on the server). Components then skip pop-ins, staggers and squash and show the end state.

#### `ThemeUtil.GetRarity(theme: Theme, rarity: string) -> (Color3, number)`
- The rarity's color and its rank in `theme.RarityOrder` (1 = lowest), so UI shows rarity by pips or a label as well as color. Unknown: `Colors.TextMuted`, rank 1.

#### `ThemeUtil.GetStyleNames() -> {string}`
- Every style name in `SharedConfigs.Themes.Styles`, sorted.

### CameraShakeUtil
Camera shake from trauma: each `Shake` adds to it, and it decays over time. Runs right after Roblox's camera, only while there is trauma. Settings: `SharedConfigs.Feel` (`Shake*`).

#### `CameraShakeUtil.Shake(intensity: number) -> ()`
- Adds `intensity` (0 to 1) of trauma. Several in a row add up, capped at 1. **Doesn't yield.**
- Ignored when `intensity <= 0` or the player has Reduce Motion on. The offset grows with trauma squared.

#### `CameraShakeUtil.Stop() -> ()`
- Sets trauma to 0 and stops the per-frame shake at once.

```lua
CameraShakeUtil.Shake(0.8) -- heavy hit, explosion
```

### HitPauseUtil
Hit pause: freezes the attacker's and target's animations for a few frames. Movement, camera and input keep going. Settings: `SharedConfigs.Feel` (`HitPauseLight`, `HitPauseHeavy`).

#### `HitPauseUtil.Pause(target: Instance?, seconds: number) -> ()`
- Freezes the animations of an Animator found under `target` (the Animator itself, or the first one inside a Model or Humanoid) for `seconds`. **Doesn't yield.**
- Does nothing for a nil target, `seconds <= 0`, or a target with no Animator.
- Only the tracks playing at the start freeze, and each goes back to its own speed when the pause ends. A second `Pause` on a paused Animator extends the pause instead of stacking.

```lua
HitPauseUtil.Pause(targetModel, SharedConfigs.Feel.HitPauseHeavy)
```

### FloatingTextUtil
Floating numbers and short words (`+10`, `-25`, `Crit!`) that rise and fade. Pooled billboards. Settings: `SharedConfigs.Feel` (`Float*`).

#### `FloatingTextUtil.Show(value: number | string, at: Vector3 | BasePart, options: FloatOptions?) -> ()`
- Shows `value` (numbers abbreviated like `1.2K`, text as is) rising from `at` (a world position, or a part it follows). **Doesn't yield.**
- At most `FloatMaxOnScreen` show at once; the oldest leaves early.
- Calls with the same `MergeKey` within `FloatMergeWindow` seconds add into the one number.
- Reduce Motion: fades in place, no rise.
- `FloatOptions` (all optional): `Color` (default theme Text), `Crit` (drawn `FloatCritScale` times bigger), `MergeKey` (any value), `Prefix` (numbers only, e.g. `"+"`), `Theme` (style name).

```lua
FloatingTextUtil.Show(25, hitPosition, { MergeKey = target, Color = theme.Colors.Negative })
```

### RewardFlyUtil
Reward icons that burst out and fly into a HUD counter. The amount is already server-confirmed; this only shows it. Settings: `SharedConfigs.Feel` (`Fly*`).

#### `RewardFlyUtil.SetTarget(name: string, target: GuiObject) -> ()`
- Registers `target` as where icons for `name` fly. A newer target replaces the older one.

#### `RewardFlyUtil.ClearTarget(name: string, target: GuiObject?) -> ()`
- Removes the target for `name`. With `target` given, only if it's still that object.

#### `RewardFlyUtil.Fly(name: string, from: Vector3 | Vector2, amount: number, onArrive: (() -> ())?, options: FlyOptions?) -> ()`
- Flies one icon per unit of `amount` (at most `FlyIcons`) from `from` (a world position, or a screen point in pixels) to the target `name`. **Doesn't yield.**
- `onArrive` runs once, when the last icon lands. It runs at once instead when nothing can fly: no target, `amount` 0, Reduce Motion, or no screen point.
- `FlyOptions` (optional): `Image` (`"rbxassetid://..."`; without one, a colored dot), `Color` (default yellow).

```lua
RewardFlyUtil.Fly("Coins", orb.Position, 5, function() SoundsService.PlaySound("Tick") end)
```

### GuideBeamUtil
A guide beam from the player's character to the next goal. One guide at a time. Settings: `SharedConfigs.Feel` (`Beam*`).

#### `GuideBeamUtil.Show(target: BasePart | Attachment | Vector3) -> () -> ()`
- Replaces any guide already shown. The beam hides while the player is within `BeamHideDistance` studs of the target, comes back if they walk away, and follows respawns. **Doesn't yield.**
- Returns a function that removes this guide. Calling it again is safe.

#### `GuideBeamUtil.Hide() -> ()`
- Removes the current guide, if any.

```lua
local hideGuide = GuideBeamUtil.Show(workspace.Shop.Counter)
hideGuide() -- when the goal is reached
```

### SharedConfigs
- `require(ReplicatedStorage.SharedConfigs)` returns:
  - `Developers: {number}`: UserIds allowed to use developer tools. See [DeveloperTools.md](DeveloperTools.md).
  - `Feel`: the feel kit's knobs (`SharedConfigs/Feel.luau`). Plain values read at use time (`Shake*`, `HitPause*`, `Float*`, `Fly*`, `Pitch*`, `Toast*`, `Beam*`), and a `Tuning` table (`{ Min, Max, Step }`, or `{}` for the Color3 `BeamColor`) that TuningSystem shows in Studio under `ReplicatedStorage.Tuning.Feel`. Read it as `SharedConfigs.Feel.X` inside the function, never copied into a local at load. Defaults come from the Feel patterns in `.claude/design/patterns`.
  - `Features`: `Disabled` (`{string}`, default empty): feature folder names whose Systems and Controllers the Loaders don't start. Used by `/import-game`.
  - `Gui`: settings for the shared Gui components: `ItemViewport` (`Folders` per Kind under `ReplicatedStorage.Assets`, `FieldOfView` 30, `DistanceScale` 2.2, `ViewDirection`), `Button` (`EdgeDepth`, `EdgeDarken`, `FaceLighten`, `ShineTransparency`), `Window` (`HeaderHeight`, `CloseSize`, `ShadowDepth`), and the motion and layout numbers of `CurrencyChip`, `PriceButton`, `ItemCard` and `Tabs`. See [Gui.md](Gui.md).
  - `Inputs`: `Contexts`, `AllowRebinding` (default false), `ReservedKeys`, `Mouse`. See [Inputs.md](Inputs.md).
  - `Monetization`: `Gamepass`, `DevProducts`. See [Monetization.md](Monetization.md).
  - `Onboarding`: `Enabled` (default false) and `MaxStep` (default 0). The tutorial runs only when `Enabled` is true and `MaxStep >= 1`. While off, onboarding never touches player data. See [Onboarding.md](Onboarding.md).
  - `Themes`: the UI looks. `DefaultTheme` (the **Plain** look every UI uses unless the user asked for a styled one: greys, Radius 0, 1 px strokes, Builder Sans, no depth or motion, `Plain = true`; its `Sounds.Hover` / `Sounds.Click` are `UIHover` / `UIClick` placeholders, skipped silently while missing), `StyledBase` (what every style starts from: real corners, depth, motion, `Plain = false`), `Active` (style used by default, `nil` = the Plain `DefaultTheme`; set only when the user asked for a styled UI) and `Styles` (one entry per style, written by `/new-reference` from Style references in `references/<Name>/`). Also exports the `Theme` type. Read it through `ThemeUtil.Get`.
  - `World`: `UseMaterialVariants` (default false; `/build-gdd`'s Looks stage sets it per game) and `MaterialVariants` (surface type -> Studs variant name; keep in step with "Surface texture" in `references/ART_STYLE.md`). Used by `MaterialUtil`.

### SharedTypes
- `require(ReplicatedStorage.SharedTypes)` returns an empty table (so Lune specs can require it). Use it only for types; every type module ends with `return {}`.
- From `ProfileType`:
  - `PlayerData` (saved): `{ Onboarding: OnboardingData, Keybinds: {[string]: string}?, CutscenesSeen: {[string]: boolean}, GamepassPurchased: {number}, PurchaseHistory: {string} }`
  - `ProfileData` (session): `{ PlayerData: PlayerData, SessionJoinTime: number }`. `SessionJoinTime` is `os.time()` at the start of the session, or 0 when no session is running.
  - `OnboardingData`: `{ Step: number, Completed: boolean }`
- From `PlumsType` (re-exported from `CustomPackages.Plums.Util.Types`): `PlumClientType`, `PlumServerType`, `PlumsClientType`, `PlumsServerType`.

```lua
local SharedTypes = require(ReplicatedStorage.SharedTypes)
local Plums = require(ReplicatedStorage.CustomPackages.Plums) :: SharedTypes.PlumsServerType
```

### ServerData
Plain tables keyed by `Player`. PlayerSystem fills them when a profile loads and clears them on leave.
- `ProfileClasses[player]`: the player's `ProfileClass` object.
- `ProfileDatas[player]`: `ProfileData` for **reads** (nil until the profile loads).
- `Plums.ProfilesPlum[player]`: the player's Plum. Write through it (`SetValue` / `ArrayInsert` / `ArrayRemove`) so the change replicates.

### ClientData
Charm atoms. Read them with `useAtom` in UI.
- `ProfileLoaded = atom(false)`: true once PlayerController has copied the server's profile into the atoms below (the Import feature's client shim waits for it).
- `ProfileData = {}`: session fields. Empty, so nothing syncs here until you add an atom, e.g. `SessionJoinTime`.
- `PlayerData` (synced from the server by PlayerController):
  - `GamepassPurchased = atom({})` (listed in `DeepSyncFields`)
  - `Keybinds = atom(nil)`: nil until data arrives.
- `Gui` (client only):
  - `OpenMenu = atom(nil :: string?)`: the name of the open Menu, or nil.
  - `Toasts = atom({})`: toasts on screen, oldest first (`{ Id, Text, Kind }`). `ToastService.Show` writes it, `Hud/Toasts` reads it.
- `Input` (client only):
  - `Device = atom("Keyboard")`: `"Keyboard" | "Touch" | "Gamepad"`
  - `MouseUnlocked = atom(false)`
  - `MouseIcon = atom(nil :: string?)`

### ServerSignals
`require(ServerScriptService.ServerSignals)` returns these groups (`Packages.Signal`):
- `Profile` ([Player.md](Player.md)):
  - `Loaded(player)`: fires once the profile is in ServerData.
  - `Removing(player)`: fires on leave, before the profile is removed and saved. Handlers must not yield.
- `Onboarding` ([Onboarding.md](Onboarding.md)):
  - `FinishStepRequested(player, step)`
  - `StepCompleted(player, step, fromClient)`
  - `Completed(player)`
- `Cutscenes` ([Cutscenes.md](Cutscenes.md)):
  - `Started(player, name)`
  - `Finished(player, name, skipped)`

## Loaders
- **Server** (`ServerScriptService.Loader`): requires every ModuleScript under `ServerScriptService.Features` (any depth) whose name ends in `System`, then `Loader.SpawnAll(modules, "Init")`.
- **Client** (`StarterPlayerScripts.Loader`): waits for `game.Loaded`, then does the same over `LocalPlayer.PlayerScripts.Features` with names ending in `Controller`.
- Modules are stored by full path (`GetFullName()`), not by name, so two Systems / Controllers with the same name in different features both start. `Loader.LoadDescendants` is not used.
- `SpawnAll` calls `module.Init(module)` in its own `task.spawn` for each one that has an `Init` function.
- Both skip modules whose feature folder (the direct child of `Features`) is named in `SharedConfigs.Features.Disabled` (empty by default; `/import-game` fills it while an imported game's old scripts still do that job).
- There is no loader for `ReplicatedStorage.Features`. Shared modules only run when something requires them.

## Data and network
- New saved fields go in `Features/Player/Server/PlayerDataTemplate.luau` and in `ProfileType.luau`.
- A field only reaches the client if it has an atom with the same name in the matching `ClientData` group.
- Remotes are defined in `network.blink` and generated into `Network/ServerNetwork` and `Network/ClientNetwork`. Regenerate them with `blink network.blink`.

## Gotchas
- **Loaders:** `Init` order is random (dictionary iteration), and every `Init` runs at the same time.
- **Loaders:** any module whose name ends in `System` or `Controller` gets loaded, even one nested inside another module.
- **ClientData:** require it as `StarterPlayer.StarterPlayerScripts.ClientData`. Any other path gives a separate copy.
- **LoopService:** with `RunPerSecond`, the elapsed time is reset to 0 before the callback runs, so the callback receives `0` instead of the real elapsed time.
- **LoopService:** callbacks are not wrapped in `pcall`. An error stops the rest of the loops for that frame.
- **SoundsService:** `PlaySound` without `Clone` or `Position` plays the **original** sound, and still applies `Volume` and `Parent` (and `Looped` / `PlayOnRemove` if given) to it permanently.
- **SoundsService:** the playlist functions only know about a playlist started in the same environment. Music driven by the server has no "current" playlist on the client, so use `SetMusicEnabled` there.
- **SoundsService:** `EnablePlaySound` and `SetMusicEnabled` called on the server would affect sounds for everyone. They are meant for the client.
- **ParticleUtil:** `DestroyAfter` without a copy destroys the original source.
- **ParticleUtil:** emitting in place on an emitter that is already `Enabled` with a Rate adds a burst on top of its normal emission.
- **GuideBeamUtil:** `LoopService`'s `RunPerSecond` is an interval in seconds, so the distance check (`{ RunPerSecond = CheckPerSecond }` with `CheckPerSecond = 5`) runs every 5 seconds, not five times a second. The beam can lag up to 5 s when it hides or comes back.
- **CameraShakeUtil:** trauma still decays while the camera is Scriptable, so a shake during a cutscene simply doesn't show. Reduce Motion is read when `Shake` is called, not every frame.
- **HitPauseUtil:** an animation that starts during a pause runs at normal speed; only the tracks playing at the start freeze.
- **FloatingTextUtil:** a merged number keeps the `Prefix`, `Color` and `Crit` of its first call. From reading the code (not run in Studio): `Animate` doesn't cancel the tweens of an earlier call, so a merged or evicted billboard may keep its old fade or rise running when it's reused.
- **RewardFlyUtil:** `onArrive` only runs when every icon's tween completes; if a tween is cancelled it never runs. The flying ScreenGui has `DisplayOrder` 10, the same as Menus.
- **SoundsService:** the auto-removal time of a copy is `TimeLength / PlaybackSpeed + 0.2`, so a pitched-up copy is removed sooner and a pitched-down one later. Neither is cut off early.
- **FeelUtil:** `ChainStep` and `PitchForStep` have no caller in `src/` yet.
